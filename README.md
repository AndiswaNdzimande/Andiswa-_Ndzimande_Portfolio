# Andiswa Ndzimande | Software Developer Portfolio

A responsive personal portfolio website showcasing my skills, experience, education and projects.



## About

I am a final-year Software Engineering student at WeThinkCode_, with a primary background in Java and backend development. This portfolio highlights my technical skills, the projects I have built and how to get in touch with me.

## Features

- Responsive layout with a mobile navigation menu
- About section with tabbed Skills, Experience and Education
- Services overview covering software development, data analysis and software testing and QA
- Project showcase with links to each live project or repository
- Contact form that delivers enquiries straight to my email inbox
- Downloadable CV

## Tech Stack

| Area | Technology |
| --- | --- |
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | Vanilla JavaScript |
| Icons | Font Awesome |
| Contact form backend | Google Apps Script |
| Hosting | Vercel |

## Project Structure

```
.
├── index.html     # Page structure and scripts
├── style.css      # Styling and responsive rules
└── images/        # Logo, project images and CV
```

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/AndiswaNdzimande/REPO_NAME.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser. No build step or dependencies are required.

## Contact Form

The form sends a request to a Google Apps Script web app, which sends your  the message to me. The script runs in my Google Sheets  and is not part of this repository.

## Deployment

The site is deployed on Vercel and redeploys automatically on every push to the `main` branch.
